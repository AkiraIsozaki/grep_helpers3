| コマンド | 流れ |
|---|---|
| `/setup-project` | docs/ideas/ の構想メモ → 文書5種を順に生成（PRD のみ人間承認） |

## スキルを増やすときの心得

客「先生! わてもひとつ、心得を書いて納めとおます。『昼寝のすすめ』ちゅうのを」

代書屋「(書きかけて)……よっしゃ、消してしもたろ。ええか、増やすんやったら作法がおます」

1. まず `writing-skills` スキルを起動しなはれ（形式・記法・検分のやり方が書いたある）
2. 形式は `skills/<name>/SKILL.md`。frontmatter は `name` / `description` のみ。description には
   「**いつ使うか**」だけ書きなはれ（内容を要約したら、看板だけ読まれて中身が素通りされる事故が起きます）
3. 全て日本語だす。他スキルへの参照はプレーン名（`` `steering` スキル``）。`@` リンクは御法度
4. 増やしたら CLAUDE.md の案内板と本 README を揃えなはれや。案内板の古い長屋は道に迷います

客「description には『いつ使うか』だけ……ほな『昼寝のすすめ』やったら『眠たいときに使用』」

代書屋「起動条件が一日中だすがな!」
