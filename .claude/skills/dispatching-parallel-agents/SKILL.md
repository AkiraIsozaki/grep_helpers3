# 並列エージェントのディスパッチ

## 概要

隔離された文脈を持つエージェントにタスクを委譲する。指示と文脈を精密に構成することで、エージェントは集中を保ち成功する。**セッション履歴は決して継承させない** — 必要な文脈だけを自分で構成して渡す。これは自分の文脈の温存にもなる。

無関係な複数の失敗（別テストファイル・別サブシステム・別バグ）を逐次調査するのは時間の浪費。各調査は独立しており並列化できる。

**基本原則:** 独立した問題領域ごとに1エージェント。並行して動かす。

## 使うとき / 使わないとき

**使う:**
- 3件以上のテストファイルが異なる根本原因で失敗している
- 複数のサブシステムが独立に壊れている
- 各問題が他の文脈なしで理解できる
- 調査間に共有状態がない

**使わない:**
- 失敗が関連している（1つ直せば他も直るかもしれない）→ まず一緒に調査
- システム全体の文脈を見る必要がある
- 探索的デバッグ中（何が壊れているかまだ不明）
- 状態やファイルを共有する（同じファイルの編集・同じリソースの使用で干渉する）

## パターン

### 1. 独立した領域を特定する

壊れているものごとに失敗をグループ化する。例: ファイルA = 分類ロジック、ファイルB = 文字コード判定、ファイルC = 進捗表示。互いの修正が影響しないことを確認する。

### 2. 集中したタスクを作る

各エージェントに与えるもの:
- **限定されたスコープ:** テストファイル1つ、またはサブシステム1つ
- **明確なゴール:** 「これらのテストを通す」
- **制約:** 「他のコードは変更しない」
- **返却形式:** 「発見と修正の要約を返す」

### 3. 同一レスポンス内で全ディスパッチ

**同じレスポンス内で全サブエージェントを起動する = 並列実行。** 1レスポンスに1件ずつでは逐次になる。

```text
Subagent (general-purpose): "tests/test_classify.py の失敗を修正"
Subagent (general-purpose): "tests/test_encoding.py の失敗を修正"
Subagent (general-purpose): "tests/test_progress.py の失敗を修正"
# 3件が並行して走る
```

## エージェントプロンプトの構造

良いプロンプトは (1) **単一領域に集中**、(2) **自己完結** — エラー本文をそのまま貼り、問題理解に必要な文脈を全部含める、(3) **返却形式を指定**。

```markdown
tests/test_classify.py の失敗3件を修正せよ:

1. test_カテゴリ値は返却で統一する — 'return' が残存
2. test_境界一致のみ採用する — 部分一致がヒットしている
3. test_判定不能時は要確認フラグを立てる — フラグが立たない

[pytest のエラー出力をここに貼る]

タスク:
1. テストを読み、各テストが何を検証しているか理解する
2. 根本原因を特定する — テストの問題か実装のバグか
3. 修正する。タイムアウト延長のような対症療法は禁止 — 真の原因を直す

制約: tests/test_classify.py と対応する実装以外は変更しない。
返却: 根本原因と修正内容の要約。
```

## ❌/✅ プロンプト対比

| ❌ 悪い | ✅ 良い |
|--------|--------|
| 「全テストを直して」（迷子になる） | 「test_classify.py を直して」（限定スコープ） |
| 「レースコンディションを直して」（場所不明） | エラー本文とテスト名を貼る |
| 制約なし（全面リファクタの危険） | 「実装コードは変更禁止」等を明示 |
| 「直して」（何が変わったか不明） | 「根本原因と変更の要約を返せ」 |

## 帰還後の検証

1. **各要約を読解する** — 何が変わったか理解する
2. **編集衝突を確認する** — 同じコードを触っていないか
3. **フルテストスイートを実行する** — `python -m pytest tests/ -q --tb=line`（個別テストではなく全件）
4. **抜き取り検査する** — エージェントは系統的な誤り（一律の誤変換・過剰な書き換え等）を犯しうる

## 利点

1. **並列化** — 複数の調査が同時に進む
2. **集中** — 各エージェントは狭いスコープで文脈負荷が小さい
3. **独立** — 互いに干渉しない
4. **速度** — 3つの問題を1つ分の時間で解決
